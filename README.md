# Prisma Foundation

A progressive learning repository covering Prisma ORM with PostgreSQL.

## Prisma Setup
See [PrismaSetup.md](./PrismaSetup.md)

## Learning Roadmap

Each learning stage is maintained in a separate Git branch.

| Branch | Topics |
| :--- | :--- |
| `main` | Project setup and shared infrastructure |
| `01-prisma-basics-crud` | Create, Read, Select, Update, Upsert, and Delete |
| `02-prisma-relations` | One-to-many relations and relational queries |
| `03-prisma-seeding` | Database seeding and reading seeded data |

## Switching Between Lessons

Switch branches to access different learning stages:

```bash
git switch main
git switch 01-prisma-basics-crud
git switch 02-prisma-relations
git switch 03-prisma-seeding
